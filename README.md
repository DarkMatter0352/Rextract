# Rextract 🦖

**Rextract** — media downloads and local AI transcription, by **speakerfreak & darkmatter**.

Download media, manage your library, and transcribe audio or video using the built-in Vibe transcription engine — all in one Windows app.

## Download Rextract

When the first signed release is published, it will appear under [Releases](https://github.com/DarkMatter0352/Rextract/releases). The Windows installer and future automatic updates will be available there.

**No public release has been published yet.** Only download installers once a tested, signed version is available.

## Updates

Rextract includes an in-app update screen. Signed automatic updates will be enabled after the first approved release and updater signing configuration are complete.
